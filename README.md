# Lab 12 — Binary Search Tree Operations

## Course
CS 20 — Advanced Programming with C++

## Objective
This lab explores the design and implementation of a binary search tree (BST), one of the most important tree-based data structures in computer science.

## Required tasks
Students must implement a BST that supports:

- insertion of integers;
- duplicate rejection;
- search and membership checks;
- deletion of arbitrary nodes;
- discovery of min and max values;
- tree height and balance analysis;
- multiple traversal methods;
- emptying the structure cleanly.

## Important note
The starter project intentionally leaves the key operations unimplemented so students must complete the actual logic and verify the design with tests.
